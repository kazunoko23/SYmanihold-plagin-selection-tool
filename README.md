# SY マニホールド選定・仕様書生成ツール

SMC SYシリーズ（SY3000/5000/7000）プラグインマニホールドの選定ツール。
ブラウザで `smc_sy_plugin_v12.html` を開くだけで動作（**完全オフライン・外部通信ゼロ**）。

## ファイル
- `smc_sy_plugin_v12.html` — **最新版**。EX600 無線リモート(WS)の生産終了告知を追加
- `smc_sy_plugin_v10.html` — 品番生成をカタログ手配例と全件突合した版
- `smc_sy_plugin_v9 (2).html` / `smc_sy_plugin_v8 (1).html` — 旧版（品番生成に既知バグあり・参照用）
- `tests/test_catalog_examples.mjs` — カタログ実在品番34件との突合テスト（`node tests/test_catalog_examples.mjs`）

## v12 での修正点（くうあつーる横断監査 2026-08-17／生成品番をSMC「品番確認」で突合）

いずれも**品番確認で成立しない品番を出していた**もの。実測の根拠を各項目に付す。

- **残圧排気弁付の記号Eの前にハイフンが必要**（`SY5300-5U1E`＝NG／`SY5300-5U1-E`＝OK。`SY7300-5U1-E`・`SY5300B-5UD1-E`もOK）
- **絞り弁付真空破壊バルブは SY3000/SY5000 のみ**（カタログ p.404 の一覧 注4）。
  **横配管形はバルブ品番に口径記号を付けない**（カタログ p.415 の手配例 `SY3A0R-5U1`）、上配管形は付ける（`SY3A3R-5U1-C6`）。
  実証: `SY3A0R-5U1`／`SY5A0R-5U1`＝OK、`SY3A0R-5U1-C6`＝NG、`SY5A3R-5U1-C6`＝OK、`SY7A0R-5U1`／`SY7A3R-5U1-C6`＝NG
  - ⚠ v12 初版では「横配管形は成立しない」と判定していたが**誤り**（口径記号を付けたまま試したため）。2026-08-21 に訂正
- **背圧防止弁内蔵Hの適用条件を実装**（`backpressAllowed()`）。カタログ p.113「※3位置およびSY7000の場合、"無記号"を選んでください」「背圧防止弁内蔵の場合は弾性体シールを選んでください」と一致。
  OK: `SY3100H`/`SY3200H`/`SY3A00H`/`SY5100H`/`SY5130H`/`SY5200H`/`SY5A00H`。
  NG: 3位置（`SY5300H`/`SY5400H`/`SY5500H`）・SY7000（`SY7100H`/`SY7200H`/`SY7A00H`/`SY7130H`）・メタルシール（`SY5201H`）
- **連数の上限は「P,Eポート取出位置」で決まる**（配線方式に関わらず共通）。カタログ「U＝U側（2〜10連）／D＝D側（2〜10連）／B＝両側（2〜24連）」。
  実証: `SS5Y3-10TC-10U`／`-10D`＝OK、`-12U`／`-12D`＝NG、`-12B`／`-16B`／`-24B`＝OK。Dサブでも同じ（`SS5Y3-10F2-16B-C6`＝OK／`-12D`＝NG）
  - ⚠ v12 初版では「TCの上限を一律10連」にしていたが、**両側Bの11〜24連まで塞ぐ誤り**だった。2026-08-21 に取出位置ベースへ訂正
- **EX500 の「SIユニットなし」の記号は無記号ではなく `0`**（カタログ p.497「eSIユニット仕様: 0＝SIユニットなし／A3N＝32点出力・マイナスコモン」）。
  実証: `SS5Y3-10S0-05D-C6`／`SS5Y5-10S0-…`／`SS5Y7-10S0-…`＝OK、無記号の `SS5Y3-10S-05D-C6`＝NG
  - ⚠ v12 初版では「無記号を廃止して EB/FA を追加」としたが、EB/FA は EX500 の記号ではない（カタログの選択肢は 0 と A3N のみ）。2026-08-21 に訂正
- **「安全スライドロックマニュアル」はマニュアル欄の記号ではなく、オーダーメイド `-X13`**（カタログ p.423「安全スライドロックマニュアル／SY3000/5000/7000-X13」）。
  マニュアル欄の記号は 無記号／D／E／F の4つだけ（p.404）。v11 が持っていた記号 G は誤りで、品番確認でも `SY3100-5UG1` 等は全てNG。
  選択不可にしたうえで「-X13 で手配」と案内する
- **「M12コネクタ」という配線方式の選択肢を廃止**。カタログの `SS5Y5-M12F1-05D` の M12 は**混合取付タイプ（M）＋12型上配管形**の意味で（p.585-586）、配線方式ではない。
  v11 は配線方式と誤解しており、選ぶと A,Bポート口径が空のまま永久に「選定中」になる死んだ選択肢だった
- **金属ベースのオールシングル配線 S・EX510 のシングル配線 S に注記を追加**。カタログ（50型 型式表示 t配線仕様）に記載があるが
  品番確認では登録が確認できない（`SS5Y3-50F1S-05D-C6`/`SS5Y3-50F2S-05D-C4`/`SS5Y3-50S5NS-05D-C4`＝NG、Sなしは OK）。選択は残し、手配前の確認を促す
- テスト: `tests/test_sy_constraints.mjs` **48件**（v12で+14）／`tests/test_catalog_examples.mjs` **34件**／公式様式記入テストも従来どおり通過

- 記号 `WS` の実体は **EX600-WSV1 / EX600-WSV2**。根拠は生産終了品ページの旧EX600-Wカタログの手配例
  「`SS5Y3-10S6WS72-05B-C6`（10型5連マニホールドベース、リモート）… EX600-WSV1」

  そちらへ誘導する
- 修正内容: ③SIユニット選択行に赤字の終了バッジ／プロトコル一覧の注記／品番生成時の注記(notes)に警告を追加
- テストを27→34項目に拡張（`tests/test_sy_constraints.mjs` に告知の存在確認と、
  現行の小型無線リモート(EXW1)には警告が付かないことの負例を追加）

なお EX600 の他プロトコルは誤爆だった: 現行SYカタログ p.601 の注意書き

## SMC公式WEBカタログ突合（2026-07-25）
SMC公式WEBカタログの「品番確認」（`webcatalog/s3s/ja-jp/detail/?partNumber=`）を判定器として、
ツールが生成しうる品番を網羅生成し（マニホールド459種・バルブ192種）SMC側と突合。
不一致をカタログ実ページで確認したうえで、以下の**カタログ制約9件**を強制するようにした
（JSY版 `jsy-manifold-tool` と共通の修正。EX250の入力ブロック上限のみ数値が異なる）。

| # | 制約 | 修正前の症状 |
|---|------|--------------|
| 1 | DINレール長さ□はバルブ連数より長いこと | 5連でD6選択→10連に増連してもD6が残留し不正品番 |
| 2 | EX250 SIユニットなし(S0)はDINレール取付不可 | `…S0-…D` を生成 |
| 3 | EX600 SIユニットなし(S60)はD0のみ（レール付Dは不可） | 警告表示のみで強制せず `…S60-…D` を生成 |
| 4 | EX245 SIユニットなし(0)は入出力モジュール④⑤とも無記号 | `…S0Y3-…` を生成 |
| 5 | EX250 入力ブロック連数上限（TA/TC=4連・TB/TD=2連） | `…STA5A-…` 等の上限超過を生成 |
| 6 | EX600 FB（PROFINET OPC UA対応）はマイナスコモンのみ | プラスコモン(2/3/6/8)を選択でき `…S6FB2-…` を生成 |
| 7 | EX600 ④無記号はSIユニットなしのみ | 読込/逆引き経由で `…S6DA-…`（④欠落）が残りうる |
| 8 | EX600 EP（CIP Safety）はマイナスコモン(PNP) | UI表示3箇所が「プラスコモン(NPN)」と逆（ロジックは元から正） |
| 9 | 節電コイル(T)はZ/NZのみ（U=無極性の設定はない） | サニタイズ未実装でJSON読込経由の `SY□□00T-5U1` が残りうる |

- SUP./EXH.ブロッキングディスクの品番をSMC側で確認（SY3000: SUP=SY30M-40-1A / EXH=SY30M-40-2A、
  SY5000・7000: SUP=EXH=SY□0M-40-1A）。**SY5000/7000はEXHに同一品番を2個**必要
  （カタログ「EA/EB両側のEXH.をブロックする場合、2ヶ必要になります」）ため、BOM・手配集約・
  構成製品リストで2個計上するよう修正した。
- 回帰テスト: `tests/test_sy_constraints.mjs`（27件）
- **【保留・未確定】JSY版とのEX250上限の差**: AS-Interface入力ブロックの上限が、
  SY側は入力ブロック仕様（2点/4点）に依存せず TA/TC=4連・TB/TD=2連、
  JSY側は入力点数ベース（TA/TC≤8点・TB/TD≤4点）と**食い違っている**。
  カタログはどちらも「最大連数に制限があります」としか記載がなく数値の根拠が取れないため、
  現状は各シリーズのSMC品番DBが受理する範囲に合わせている（＝どちらも不正品番は生成しない）。
  物理的には点数ベースが妥当に見えるが確証がないので**どちらかへの統一は保留**。
  確定情報（EX250取扱説明書の入力点数仕様など）が得られたら再検討すること。

## 品番逆引きUI・公式仕様書記入の検証（2026-07-28）
ランダムな実在品番での逆引きと、SMC配布の仕様書テンプレ11種への記入を実機（ヘッドレスChrome）で検証し、
以下を修正した。

**品番逆引き**
- 逆引き直後だけステップ6（バルブ連数）の表示が「—」のままだった
  （`valve-val`と完了マークは更新するのに`sv6`だけ更新漏れ。連数を±1すると直る表示バグ）
- 逆引きで構成を復元した後も初回オンボーディングの吹き出し
  「まずはここから：バルブシリーズを選択」が残っていたので、復元時に解除するようにした
- 検証: 実UI操作14件・逆引きAPI40件・マニホールド＋バルブCSV14件すべて再生成一致（consoleエラー0）

**公式仕様書「◆マニホールド型式」ボックスの記入位置ずれ（重要）**
テンプレのタイトルから取った型式コードがボックスの固定表記と一致しない場合、基準列が`SS5Y□`まで
後退し、その手前の「―」を区切りと誤認してグループが丸ごとずれていた。
- 例: `SS5Y5-10F-B` はタイトルが「Dサブコネクタ対応：SS5Y5-10F/FW」→ 型式コード`10F`、
  ボックス側の固定表記は`10`のみ。結果、コネクタ種類`F`・取出方向`1`の枠に連数`05`とP,E`D`が入り、
  口径の枠に`C8`が入る（`SS5Y5-1005D-C8`）誤記入になっていた
- 影響: `SS5Y5-10F-B` / `SS5Y5-12L+-A` / `SS5Y5-M10M-A` / `SS5Y5-M11M` の4種
  （固定表記が完全一致する他7種は元から正しい）
- 修正: 固定表記を**実セルから**求める（`SS5Y□`の後、最初の記入枠までの値入りセル。混合取付の
  `Ｍ`+`10M`のように複数セルに分かれる場合は連結し全角→半角に正規化）。残り記号の切り出しも
  この固定表記基準に変更し、リード線`L1/L2/L3`等をトークンに追加
- 検証: 11種すべてで型式ボックスを左から連結すると選定品番と完全一致。仕様欄（連別）・
  構成製品リスト・ご発注品番欄も11/11で期待どおり

- 回帰テスト: `tests/test_official_form_modelbox.mjs`
  （テンプレはSMC配布物のためリポジトリに含めない。展開済みフォルダを引数で渡す。
  　`node tests/test_official_form_modelbox.mjs <フォルダ>`。未指定・未導入時はSKIP）

## 金属ベース50/51/52型テンプレでの様式突合（2026-07-29続）
金属ベース用テンプレ6種（50P/50PH/51P×2/52PH/52F）で検証し、型式ボックスの構造差に対応した。
- **金属テンプレは型式ボックスの枠の間に印字済みセルが挟まる**
  （例: `50 [外部パイロットR枠] P [方向・配線仕様枠]`、51型はP,E取出`D`が印字済み）。
  枠だけを数えて値を配る従来ロジックでは `50PP2S`・`05DD` のように印字と重複記入されるため、
  印字済みセルを認識して「印字が担う値は書かず、その手前の枠も空ける」よう修正（JSY版にも同修正）
- 検証: 金属6種すべてで型式ボックスが選定品番と完全一致。既存テンプレ17種にも回帰なし
  （`tests/test_official_form_modelbox.mjs` = 23種に拡充）
