# JSY版 マニホールド仕様書作成ツール 設計書

作成: 2026-07-13 ／ ベース: `smc_sy_plugin_v10.html`（SY版・手配例テスト34/34）
データソース: `S11-110-JSY.pdf`（DL）、`JSY_plugin_valid_models.xlsx`（全14シート・カタログ突合済）

## 1. スコープ

- **対象: JJ5SY（JSYプラグイン コネクタ接続ベース）10型 横配管形のみ**
  - SY版にあった「ベース種類（金属/混合）」「配管形式（裏/上配管）」の選択ステップは**丸ごと不要**
  - ノンプラグイン（40/41型金属・20型直接配管）は対象外
- シリーズ: **JSY1000 / JSY3000 / JSY5000**（記号 1/3/5）
- 将来フェーズ（v1では品番表示のみ・選定UI無し）: ZK2連結（JSY3000のみ・末尾-M）、サブプレート単体（3000/5000・JSY□1M-27P-1-W□-□）

## 3. 配線方式（S11-110の接続方式・ページ区分準拠）

**採用**: Dサブ F(IP40)/FW(IP67)/**FC(IP20コンパクト)**、フラット P(26)/**PC**/PG(20)/**PGC**/PH(10)/**PHC**、
端子台 T/TC、リード線 L1/L2/L3×長さ1/2/3、小型無線リモート SW□（S0/SW1〜SW3N）、
EX600（S6□・CIP Safety EP含む）、EX245（**JSY3000/5000のみ・直接取付のみ**）、EX250（生産中止予定）、EX260（PROFIsafe FPN/DPN含む）、EX120（S3□）

**SYにあってJSYに無い**: EX500 / EX510 / EX126 / EX180 / マルチコネクタM / M12
**注意**: コネクタ取出方向は 1=上向き/2=横向き（P.22。※ZK2ページのみ2=下向き表記）。FW/FC/PC系は回転不可。

## 5. 品番エンジン

### マニホールドベース
`JJ5SY[1/3/5]-10[接続方式記号][取出方向等]-[連数][P,E位置(+給排気)]-[口径][取付]`
- 例: `JJ5SY3-10F1-05D-C8` / `JJ5SY3-10S6Q72-05B-C6`（EX600の④極性+⑤I/O連数はSY v10と同じ組み方）
- **SYとの構造差はほぼ無し** → buildPN()の型式部だけ差し替えで流用可
- 口径: JSY1000=C2/C4/C6/CM（**C2,C4はピッチ6.5mm・C6は9mm**）、JSY3000=C4/C6/C8/CM、JSY5000=C6/C8/C10/C12/CM。P,Eポート=ø10（3000）※1000/5000のP,E径は実装時にカタログ確認
- 取付: 無記号/D/D0/D3〜24。EX245は直接取付のみ。CIP SafetyはD0のみ（DINレール別手配）

### バルブ（SYより大幅に簡素）
`JSY[1/3/5][切換1-5,A,B,C][コイル無/T]00?→（構成: JSY❶❷❸❹-5❺）`
実形式: `JSY[❶][❷][❸コイル][❹保護回路]-5[❺マニュアル]` 例: `JSY3100-5U`
- ❸コイル: 無記号=標準/T=節電。**JSY1000はTのみ**
- ❹保護回路: U(無極性・**JSY1000非対応**)/Z(プラスコモン)/NZ(マイナスコモン)。節電時はZ/NZのみ。安全通信(EP/FPN/DPN)はU/NZのみ＋2位置ダブル不可＋マニュアルロック式不可
- ❺マニュアル: 無記号/D/E（**JSY1000はE非対応**）
- **シール（弾性体のみ）・パイロット・背圧防止弁・電圧（DC24Vのみ=5固定）・取付ねじの選択は無い** → バルブ編集UIの行数が半減
- SI極性とバルブコモンの整合チェック（プラス→U/Z、マイナス→U/NZ）を適合チェックに追加

## 6. 流用資産（SY v10からそのまま使うもの）

- UI骨格全部: ステップウィザード/SVG（左端配線ブロック・P/E帯・凡例・増連＋・寸法線）/右パネル/品番バー未入力ガイド/保存・読込/ソレノイドメーター
- Excel4シート出力（選定仕様書/BOM/マニホールド仕様書グリッド/＊付き手配集約）
- **公式仕様書自動記入エンジン**（ZIP直接編集・アンカー検出）: JSY用公式テンプレは `JJ5SY□-10□□` をタイトル照合に追加するだけで動く見込み（テンプレ入手後に検証）
- テストハーネス: S11-110の手配例で新規に組む（例: `JJ5SY3-10F1-05D-C8`+`＊JSY3100-5U`、`JJ5SY3-10S6Q72-05D-C8`、ZK2手配例）
- 寸法線ピッチ: JSYはカタログ寸法式から要抽出（JSY1000は口径でピッチが変わる点に注意）

## 7. 実装手順

1. `jsy_plugin_v1.html` としてv10をコピー → データ層差し替え（WIRING_DEFS/CM/AB_COMPAT/limits/シリーズ記号）
2. ベース種類・配管形式ステップ削除、取付方法の銘板オプション削除
3. バルブ編集UI簡素化＋バルブPNエンジン差し替え（valve seal/pilot等の削除）
4. オプション互換表をJSY用に（スペーサ類の品番テンプレ=JSY□0M-…はカタログP.134等で要確認）
5. tests/test_jsy_catalog_examples.mjs（手配例突合）
6. SVG微調整（左端ブロックにEXW1/EX245等の対応済み分岐はそのまま）
7. 公式仕様書テンプレ（JJ5SY用）での自動記入検証
